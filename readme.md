# Credit Card Statement Analyser and Spend Categoriser

## Domain

Consumer Finance

## Problem

Credit card statements contain transaction information that can be difficult to analyse manually. Merchant names may be truncated or cryptic, recurring subscriptions may be difficult to identify, and foreign currency transactions may contain separate markup charges.

## Features

- CSV statement upload
- PDF statement parsing
- Data cleaning
- Merchant descriptor normalization
- Merchant categorisation
- Recurring subscription detection
- Monthly spending analysis
- Category-wise spending
- Merchant-wise spending
- Foreign currency transaction detection
- Foreign transaction markup handling
- Interactive dashboard
- Downloadable CSV report

## Technologies

- Python
- PyCharm
- Streamlit
- Pandas
- Plotly
- pdfplumber
